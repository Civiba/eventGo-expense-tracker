# eventGo-expense-tracker
A mobile-friendly expense tracker for office use with multi-user support, file uploads, and Excel/ZIP exports


## Features

- 📱 **Mobile-friendly** - Works on phones and desktops
- 👤 **Multi-user support** - Employees & Senior roles
- 📝 **Self-registration** - Users can create accounts
- 📄 **Bill uploads** - Upload receipts (JPG, PNG, PDF)
- 📁 **Project management** - Organize expenses by project
- 📊 **Excel & ZIP exports** - Download reports and receipts
- 🔒 **Role-based access** - Employees see only their bills

## Tech Stack

- **Backend**: Node.js, Express.js
- **Database**: MySQL
- **Authentication**: JWT (plain text passwords for demo)
- **File Upload**: Multer
- **Frontend**: HTML, CSS, JavaScript (vanilla)

## Prerequisites

- Node.js (v14 or higher)
- MySQL (v5.7 or higher)
- npm or yarn
